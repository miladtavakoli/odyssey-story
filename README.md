# پیش از اودیسه

سایت داستانی تعاملی دربارهٔ پیش‌زمینهٔ جنگ تروا و ورود به داستان «اودیسه»، به زبان فارسی.

## راه‌اندازی

کافی است `index.html` را با مرورگر باز کنید. سایت با HTML، CSS و JavaScript خام ساخته شده و نیاز به نصب کتابخانه، سرور یا دیتابیس ندارد.

در صورتی که به اینترنت متصل باشید، فونت Vazirmatn از Google Fonts بارگیری می‌شود؛ در حالت آفلاین سایت با فونت جایگزین نمایش داده خواهد شد.

برای انتشار آنلاین می‌توانید محتوای این پوشه را در GitHub Pages، Netlify یا هر میزبان فایل‌های استاتیک قرار دهید.

## امکانات

- هشت فصل داستانی از داوری پاریس تا آغاز سفر اودیسئوس
- انیمیشن کشتی، سیب طلایی، آسمان شب و صحنهٔ اسب تروا
- نقشهٔ شماتیک قابل کلیک از پادشاهی‌ها و متحدان دو جبهه
- کارت‌ها و نمودار تعاملی روابط شخصیت‌ها
- خط زمان ده‌ساله با کنترل کشویی و نمودارهای مقیاس زمانی
- مقایسهٔ تفاوت‌های فیلم Troy (2004) و روایت‌های اسطوره‌ای
- واکنش‌گرا، راست‌به‌چپ، و پشتیبانی از تنظیم «کاهش حرکت» در دستگاه

## دقت تاریخی

روایت اسطوره‌ای و بازسازی آموزشی است، نه تاریخ‌نگاری قطعی. برخی وقایع از سنت‌های متنوع یونان باستان، خارج از متن ایلیاد، آمده‌اند. مسیرها روی نقشه شماتیک‌اند. جزئیات خود سفر اودیسئوس عمداً افشا نشده‌اند. منابع در انتهای سایت لینک شده‌اند.
